# ByteSpace New

A responsive landing page built for the Jr. Software Engineer (Frontend) assessment, based on the provided Figma design.

**Live demo:** https://bytespace-ixx9uaffn-me-13c5.vercel.app/

## Tech Stack
- React + TypeScript
- Vite
- Tailwind CSS

## Features
- Full landing page matching the Figma design
- Responsive layout (mobile, tablet, desktop)
- Reusable components (Navbar, Hero, Button, Footer, etc.)
- [Login and Signup pages with form validation, if you built them]

## Getting Started

1. Install dependencies
   npm install

2. Run the dev server
   npm run dev

Then open http://localhost:3000.

## Project Structure
- `src/` : app source code
- `components/` : reusable UI components
- `public/` : static assets
